# SANAD — Smart Companion Prototype for Medication & Chronic Care (Health Hackathon)

Two-view prototype connecting older adults and companions with AI-assisted medication tracking, alerts, and chronic care support.

## Key Features
* **Companion View:** Create an account, add patient details and a pairing code, add medications to test AI interaction checks and smart alerts, track status, and copy the doctor summary.
* **Older Adult View:** Sign in with the pairing code, confirm medication intake with audio and visual alerts, log blood sugar readings with clear color feedback, and use the help button.
* **AI, Privacy & Future Scope:** AI drug interaction checks, camera reading for medication boxes and glucose meters, Saudi-dialect voice understanding, non-diagnostic pattern alerts, user consent, data encryption, and future plans for live AI/database integration, multiple companions, offline alerts, and Sehhaty integration.

## How to Try It
Start in the Companion tab to add patient details, a pairing code, and a medication, then switch to the Older Adult tab and enter the code.
